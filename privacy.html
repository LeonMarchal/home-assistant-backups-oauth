Privacy Policy

Home Assistant Backups is a personal application used to upload Home Assistant backups to the owner's Google Drive using rclone.

Data Access

The application accesses Google Drive only to create and manage backup files.

Data Storage

Backup files are stored in the owner's Google Drive account. Google authentication credentials are stored locally on the owner's server.

Data Sharing

The application does not sell or share personal data with third parties. Google Drive is used to store the backup files.

Data Deletion

The owner can delete backup files from Google Drive and revoke application access through their Google Account settings.
